# Agent instructions

Before you use UI SDK, follow the `ui-sdk` skill in `.agents/skills/ui-sdk`.
Read `node_modules/@ui-sdk/react/docs/llms.txt` first. Then read only the component pages that you need.
To build a new component, search `node_modules/@ui-sdk/react/docs/core.md` by heading.

Write documentation in Simplified Technical English. Use short sentences and active voice.

Run `pnpm verify` before you commit.
